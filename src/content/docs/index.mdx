这个项目使用 Astro 与 Starlight。页面源码都在 `src/content/docs/` 中；打开源码，可以同时看到写法与网页中的实际效果。

## 选择合适的写法

<CardGrid>
  <Card title="日常说明用 Markdown" icon="document">
    新建 `.md` 文件即可编写正文、代码块、表格和提示框，适合大多数说明文档。

  <Card title="组合界面用 MDX" icon="puzzle">
